# 小笺项目

当前软件版本：**1.2.0**。双击 `01软件/小笺/小笺.exe` 启动。

| 目录 | 内容 |
| --- | --- |
| `01软件/小笺` | 当前可直接运行的软件及完整运行依赖。请保持整个目录完整。 |
| `02安装包` | 按版本存放安装程序：1.2.0 为当前新版，1.0.0 为历史版本。 |
| `03源码` | 可编辑代码：`desktop` 为桌面入口，`dist` 为界面代码，`scripts` 为构建和验证工具。 |
| `04备份/应用包` | 1.0.0、1.1.0、1.2.0 的应用包快照，用于恢复程序。 |
| `04备份/旧版源码` | 原版前端代码存档。 |
| `04备份/历史修改脚本` | 早期升级及目录整理脚本，仅供查阅，不重复执行。 |
| `04备份/用户数据` | 放置软件导出的 JSON 数据备份。 |
| `05预览` | 界面验证截图，验证脚本会更新这里的截图。 |
| `06文档` | 使用及更新说明。 |

## 修改和验证

在项目根目录运行：

```powershell
node .\03源码\scripts\verify.cjs
node .\03源码\scripts\verify-time.cjs
node .\03源码\scripts\build-asar.cjs
node .\03源码\scripts\build-installer.cjs
```

构建前退出小笺。构建脚本会将应用包写入 `01软件/小笺/resources/app.asar`，历史版本自动保存到 `04备份/应用包`。这些脚本按自身位置解析路径，也可从其他工作目录调用。

安装包使用 electron-builder 和 NSIS 构建，配置为 `03源码/electron-builder.json`。工具依赖在 `03源码/build-tools`，下载缓存、构建日志及安装包验证文件在 `04备份/构建缓存`。首次构建需要联网下载工具。

验证脚本使用本机配置的 Playwright 和 Edge。源码来自已打包应用的提取文件，没有原始完整开发仓库；`dist` 中的 HTML、CSS、JS 是当前可维护的界面源码。

## 备份与安装包

**程序备份和用户数据备份分开存放。** 应用包快照不包含日志、加班和调休等个人记录。请在软件的“数据管理 → 导出备份”中导出 JSON，再放入 `04备份/用户数据`。

当前安装包：**`02安装包/1.2.0/小笺-安装版-1.2.0-x64.exe`**。支持中文安装向导、选择安装目录和创建桌面及开始菜单快捷方式。`SHA256.txt` 用于校验安装包文件。

详细功能、统计规则和恢复方法见 `06文档/更新说明.md`。
