## 修改和验证

在项目根目录运行：

```powershell
node .\03源码\scripts\verify.cjs
node .\03源码\scripts\verify-time.cjs
node .\03源码\scripts\verify-storage.cjs
node .\03源码\scripts\build-asar.cjs
node .\03源码\scripts\prepare-distribution.cjs
node .\03源码\scripts\verify-desktop.cjs
node .\03源码\scripts\build-installer.cjs
```

构建前退出小笺。构建脚本会将应用包写入 `01软件/小笺/resources/app.asar`，历史版本自动保存到 `04备份/应用包`。这些脚本按自身位置解析路径，也可从其他工作目录调用。

安装包使用 electron-builder 和 NSIS 构建，配置为 `03源码/electron-builder.json`。工具依赖在 `03源码/build-tools`，下载缓存、构建日志及安装包验证文件在 `04备份/构建缓存`。首次构建需要联网下载工具。

验证脚本使用本机配置的 Playwright 和 Edge。源码来自已打包应用的提取文件，没有原始完整开发仓库；`dist` 中的 HTML、CSS、JS 是当前可维护的界面源码。

## 备份与安装包

**程序备份和用户数据备份分开存放。** 应用包快照不包含个人记录。桌面版默认使用安装目录中的 `小笺数据/记录/records.json` 保存记录，`小笺数据/备份` 保存自动和手动备份。安装目录无法写入时使用文档目录下的 `小笺数据`。

在软件“设置”中查看、修改或打开记录及备份目录。更换记录目录会复制当前记录和已有备份，原文件保留；所选目录已存在记录时不会覆盖。更换备份目录会复制现有备份。也可以将备份位置设为本项目的 `04备份/用户数据`。

旧版记录保存在 `%APPDATA%/xiaojian-sticky-life/Local Storage` 中；桌面版首次启动且新记录文件不存在时自动迁移旧版记录。旧缓存仍保留。设置文件为 `%APPDATA%/xiaojian-sticky-life/storage-config.json`，保存所选目录、自动备份开关和保留数量。网页预览仍使用浏览器本地存储，目录设置需桌面版。

每天首次保存前备份修改前的数据，默认保留最近 30 份自动备份；手动备份始终保留。软件的“导出备份”和设置中的“立即备份”直接写入所选备份文件夹。只替换记录文件用于导入恢复，安装程序不会打包个人记录；卸载时也保留个人数据目录。

当前安装包：**`02安装包/1.3.0/小笺-安装版-1.3.0-x64.exe`**。支持中文安装向导、选择安装目录和创建桌面及开始菜单快捷方式。`SHA256.txt` 用于校验安装包文件。

1.3.0 清理了旧功能的无用样式，只保留中文和英文回退语言包，并排除调试日志、旧卸载程序及个人数据。软件运行目录由约 368 MiB 减至 320 MiB，安装包由约 109 MiB 减至 101 MiB；详细数据见 `06文档/体积优化.json`。Electron 引擎、渲染依赖和许可证文件保留。

详细功能、统计规则和恢复方法见 `06文档/更新说明.md`。
