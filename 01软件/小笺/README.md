# 小笺 1.3.0 运行目录

[下载完整运行目录 ZIP](https://github.com/xing95/xiaojian/releases/download/v1.3.0/xiaojian-portable-1.3.0-x64.zip)。解压后运行 `01软件/小笺/小笺.exe`，保持整个目录完整。

完整程序及 Electron 运行依赖通过 GitHub Releases 分发。仓库保留当前 `resources/app.asar`、许可证及发行文件 SHA256 清单。

发行包不含 `小笺数据`、个人记录、自动或手动备份、日志与存储设置；首次启动会创建本地数据目录。更新现有软件前请导出个人数据备份。
